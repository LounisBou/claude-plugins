# The question

In this shape:

```
**Question i of N**
_Subject_ : <a few words>
_Context_ : <two to six sentences: the stake, what is known>
_Question_ : <one sentence ending in a question mark>
_Choices_ :
- **A** : <the choice> — cost: <…> — gain: <…>
- **B** : <the choice> — cost: <…> — gain: <…>
_Free answer_ : <or answer in your own words>
_Recommendation_ : A — <why it beats the others>
```

- Two to five choices, A to E, each a materially different piece of work, not a shade of one.
- The free answer is always open and never opens on a lone letter.
- The recommendation argues its letter against the others; a bare letter is none.
- Name every item in plain words (what breaks, for whom, what it costs him) and by its pull
  request with the repository name; a tracking-table row number may follow, never alone.
- A host dialog, only for a session nobody waits on (`SKILL.md`): the recommended option first
  and marked, « Other » for the free answer.
- The answer is recorded, dated, where the work keeps them.
- Orchestrator plugin: ask with `ask`, close with `settle`, no block.
- Never ask what the spec or the code answers. Answer him first, check the premise after.
  Asked again for what you failed to deliver, say you failed, answer, offer a fresh session.
